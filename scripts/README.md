# Repository commands

[Repository home](../README.md)

- [build_latex.sh](build_latex.sh) builds the two documents under `paper/` using
  a local TeX installation and writes their PDFs under `build/`.
- Dataset EDA commands live under [EDA/](../EDA/README.md).
- Experiment-specific commands stay with their [study folders](../experiments/README.md).

Run repository commands from the repository root. Follow each study's README
for its own working directory, environment, model downloads, and execution limits.
