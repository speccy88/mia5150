# Source and provenance register

Inspected October 2, 2026. Public documentation was read through web tools. Direct network access from the execution container failed, so no real backbone, tokenizer, dataset or CUDA dependency stack was downloaded here.

## SkillRet

- https://huggingface.co/datasets/ThakiCloud/SKILLRET
- https://huggingface.co/datasets/ThakiCloud/SKILLRET/raw/main/README.md
- https://github.com/ThakiCloud/SKILLRET
- Paper: https://arxiv.org/abs/2605.05726

Dataset reference starts from documented revision prefix `a050ad2`; `fetch.py` resolves it to a full SHA **before** downloading. The full SHA and file SHA-256 values are recorded locally and must be reused for test. The full SHA could not be resolved in this container and has not been invented. Stop on resolution/count mismatch.

Exact upstream JSONL paths: `data/{skills,queries,qrels}/{train,test}.jsonl`. Dataset card: Apache-2.0; preserve its citation and source attribution. Original skill metadata includes per-skill licensing; do not assume retrieved Markdown grants arbitrary execution or external resource access.

## JevK5

- https://github.com/allebee/jevk5
- https://raw.githubusercontent.com/allebee/jevk5/v0.3.0/jevk5/prompt.py
- https://raw.githubusercontent.com/allebee/jevk5/v0.3.0/jevk5/runtime.py
- https://raw.githubusercontent.com/allebee/jevk5/main/training/lora.py
- https://huggingface.co/alibiserikbay/JevK5
- https://huggingface.co/alibiserikbay/JevK5/commit/c4f7fdb3aeab5582336406e78d3bef11bf98833d

Model weights pinned to `c4f7fdb3aeab5582336406e78d3bef11bf98833d`. Runtime installation requests tag `v0.3.0`, then records the resolved git commit. The training source inspected was main; this kit implements its own transparent loop with multi-positive ranking evaluation and checkpointing rather than treating mutable upstream defaults as a frozen contract. JevK5 code/weights: Apache-2.0.

The upstream source confirms letter-logit readout, soft `gold_probs`, attention-target LoRA, and the FLA backward compatibility gate. It also shows that generic training accuracy uses target argmax and that overly long inputs are skipped. Those defaults are not adopted in this package's SkillRet scorer/converter.
