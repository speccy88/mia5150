# Start here

Read [README.md](README.md) for the current fresh-checkout instructions, measured
results, private key setup and exact commands. Read [ARCHITECTURE.md](ARCHITECTURE.md)
for the method and code map, then [VALIDATION.md](VALIDATION.md) for packaging checks.

The immutable [reference run](reference_run/README.md) contains the original
executed notebooks, sanitized raw traces, costs and failures. Its original
START_HERE.md describes that historical workspace. Use this folder's README for
new runs; do not copy historical ledgers or model answers into the runtime folders.

`CODEX_TASK.md`, `PLAN.md` and `ACCEPTANCE_CHECKLIST.md` preserve the original brief
and execution history. They are not instructions to spend credits on opening the
repository. No API key is included, and paid generation is disabled without local
permission and the persistent guard.
