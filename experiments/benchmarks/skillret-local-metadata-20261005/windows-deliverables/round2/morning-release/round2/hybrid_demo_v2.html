        Metric definitions and failure behavior

        Recall@k is relevant skills found in the first k divided by all relevant skills for that query. Completeness@k is 1 only when every relevant skill is found. The pool ceiling counts relevant skills anywhere in the candidate pool. An invalid or unattempted benchmark rerank receives an empty ranking and zero metrics while retaining its query denominator. A production fallback may serve the retrieval result; its metrics are shown separately. Failure simulation never changes saved results.

        Budget and provenance

        Standalone offline snapshot. No live API controls, external assets, credentials or network requests. Existing historical panels remain separate from the six-query BM25 screen. Hosted TypeSafe Jev is not the locally cached JevK5 model.
