# J00 — Audit and freeze

Inspect the existing selected repository without rewriting it. Identify dataset loaders, model adapters, metric code, cache keys, result files and historical execution environments. Capture git status and available disk/RAM/GPU information without exposing secrets. Read the supplied proposal and the bundle's benchmark contract.

Determine which SkillRet version each existing run used. Inventory all previously consulted test queries AND aggregate results. Distinguish a development slice, public benchmark feedback, and genuinely unseen confirmation. A fresh split of public training rows is not unseen by the released SkillRet models. Propose an independent panel if historical public-test use prevents a pristine holdout claim.

Inspect query construction for leakage from gold IDs/names/counts. Inspect metrics for multi-positive handling, cutoffs, duplicate ranks, missing-query denominators and invalid output handling. Verify that the currently used Jev/JevK5/Plumb/CLM adapter is identified correctly and uses its native readout.

Add only the smallest necessary validation scaffolding. Run offline tests and preserve original evidence. Prepare immutable-manifest schemas for dataset, model/tokenizer, code, query partitions, corpus views and candidate pools. Do not assume the published reference scores were reproduced by this bundle.

Acceptance: an audit report with exact inspected paths, observed hardware/access, an exposure ledger, explicit unresolved fields, test outputs and a narrowly scoped J01 plan. Request a concrete resource cap before a paid pilot. Do not create pods, query paid APIs or start training in this job.
