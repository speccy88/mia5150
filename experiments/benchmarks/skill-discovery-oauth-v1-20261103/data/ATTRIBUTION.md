# Source attribution for the metadata excerpts

`ATTRIBUTIONS.jsonl` retains the received author handle, source repository, declared
license, source URL and raw URL for each of the 6,006 skill IDs, in source order.
The received labels are 5,270 MIT and 736 Apache-2.0. They are source metadata,
not an independent legal review or a blanket license for this study's code or models.
The linked upstream files/repositories retain their original license and notices.
Only ID, name and the first 300 description characters are used in the model prompts;
the attribution companion is never inserted into those prompts. Full skill bodies
are excluded. No duplicate name or source attribution was silently removed.
