# SkillRet experiment index

This index maps recorded work to its code and evidence. Studies now live under the [grouped experiments directory](experiments/README.md), with their internal source/results layouts preserved. The 7 October consolidation adds the completed full-text branch and the October 5-6 local studies without rewriting history or rerunning inference, training, or hosted requests.

Browse the [17-study benchmark catalog](docs/SkillRet-Benchmark-Catalog.md) for execution environments, dataset/query scope, recorded metrics, source links, and completion limits.

All recent SkillRet query panels use previously exposed public data. A full catalog or a full query count does not make an evaluation blind. Scores from different document views, token limits, pools, and panels are not directly interchangeable.

## Implemented, incomplete, and unrun work

The metadata experiment's [execution table](experiments/benchmarks/skillret-local-metadata-20261005/EXECUTION_STATUS.md) is authoritative for its scope. Its 32K full-catalog prompt diagnostic, SRA/SkillReason frozen full-catalog transfer, 21-option multipass selection, and 16-query native escalation latency study were not run. Its original quantized Qwen8 reranker and local 4B candidate-ranking experiments were blocked/incomplete. Full-body 1,024-token and six-field runs were partial. Later scaling Qwen8 diagnostics are a separate bounded experiment and do not complete those earlier runs.

The full-text hosted study's [expansion decision](experiments/benchmarks/skillret-embedding-jev-fusion/results/full_expansion_decision.json) declines the 4,392-query hosted expansion. SearchJev's completed count is 20 updates. Scaling selector and reranker rows retain failures in their denominators and are two-query diagnostics. No new experiments, paid requests, or GPU work were performed during consolidation.

## Publication and reproduction

[Publication audit](docs/publication/artifact-publication-audit/README.md) records source ownership, canonical ZIP hashes, export hashes, large-file omissions, offline validation, and export-only redactions of public benchmark credential-shaped examples. Original request payload filenames/hashes describe historical bytes; redacted exports must never be treated as exact-payload retry inputs.

Downloaded multi-gigabyte base weights, environments, dependency caches, large upstream skill-body corpora, and duplicate ZIP deliveries stay local. Small trained adapters and checkpoint evidence are included. Saved runtime scripts may contain original absolute paths; use each experiment README and pinned manifests when rebuilding assets.
